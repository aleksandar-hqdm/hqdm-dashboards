Why CM&D is not ranking · 5 gaps

  1. P0 Site doesn't back the GBP. 27 GBP service items across 6 categories. Site has 1 service page. /bathrooms is 65 words with no H1.
  2. P0 Spam-pattern suburb URLs. 9 suburb pages use junk modifiers (dependable / efficient / trusted / fast / quality ×2 / premium / local / skilled) + generic "-general-contractor-in-X-or" stem. Underlying copy is salvageable.
  3. P0 Zero schema everywhere. No LocalBusiness / Service / AreaServed JSON-LD on any page. Wix theme is not emitting.
  4. P1 No tracking. No GTM, GA4, Clarity, Meta Pixel. GBP UTM is correctly tagged but nothing's listening.
  5. CTX 6 reviews vs leaderboard median 26 (NW Tub & Shower leads at 841). Below the local-pack floor. Out of HQDM scope — client-owned action; surface as context.

The 90-day plan · 5 workstreams

D1 · P0 · HQDM on-page + content
Service-page rebuild — the core fix

Build the service pages the GBP claims and the site doesn't back. June: /bathroom-remodeling/ + /walk-in-shower-conversion/. July: /kitchen-repair/ + /kitchen-remodeling/ rebuild. August: /general-contractor/ + one P2. Spec: 1,200-1,500 words, Service+AreaServed schema, suburbs block, FAQ, click-to-call. Mirror Marylhurst page voice.

D2 · P0 · HQDM dev (Milan)
Schema — LocalBusiness + Service + AreaServed

JSON-LD injection via Wix custom code (Settings → Custom Code → Head). GeneralContractor on every page with CCB #112648, WA #CONSTMD742DF, geoCircle + 8-city areaServed. Service per service page. BreadcrumbList on non-home. Single rollout · June.

D3 · P1 · HQDM on-page + dev
Suburb-page URL repair — keep content, fix slugs

Rename 9 suburb URLs to clean /west-linn/, /marylhurst/, /willamette/, etc. 301s from old. Drop junk modifier in title + H1. Keep body copy. M2-M3: add service-suffix children (/marylhurst/bathroom-remodeling/) as parent service pages land = the service × suburb matrix.

D4 · P1 · HQDM dev
Tracking install — GTM + GA4 + 4-event model + Clarity

GTM via Wix Marketing Tools. GA4 base + form_submit · contact_form_submit · click_phone_number (tel: clicks) · gmb_click (utm_campaign=gbp landings). Validate in DebugView. Single rollout · June.

D5 · P2 · HQDM AM team (Matt/Andrew/Racquel)
GBP — tight surface (no reviews/Q&A/photos)

M1: link each GBP service item to its new site page via per-item "Learn more" (after D1 ships). M3 (August): single 30-day primary-category test — swap "Construction company" to "Home builder" or "Kitchen Renovator" AFTER schema + pages have settled. Description, secondary categories, items: no change needed.
